# 🛡️ CarShield - نظام درع السيارة الذكي
تطبيق متكامل لحماية خصوصية أصحاب السيارات وتوليد ملصقات QR ذكية وإرسال إشعارات فورية مع اتصال VoIP مشفر.

## 🚀 كيفية الرفع إلى GitHub:
```bash
git init
git add .
git commit -m "feat: initial CarShield release"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/carshield.git
git push -u origin main
```

## 📱 تعديل التطبيق للهاتف بدون حاسوب:
1. اضغط على زر '.' في صفحة مستودع GitHub لفتح محرر الويب السحابي.
2. عدل نصوص وألوان التطبيق من ملف 'src/types.ts'.
3. ثبّت التطبيق على هاتفك كـ PWA أو حوله لـ APK عبر pwabuilder.com.
